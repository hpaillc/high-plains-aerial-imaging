# High Plains Aerial Imaging LLC — V4.0

## Projects Gallery

This revision replaces the placeholder Projects panels with three distinct Wyoming-focused project visuals:

1. Agriculture & Drone Spraying
2. Oil & Gas / Pipeline
3. Ranching & Livestock

### Files

- `images/project-agriculture.jpg`
- `images/project-oil-gas.jpg`
- `images/project-ranching.jpg`
- `v4-0-projects-gallery.css`
- `v4-0-projects-section.html`

### Install

1. Upload the three JPG files into the repository's `images` folder.
2. Open `styles.css`, go to the bottom, and paste `v4-0-projects-gallery.css`.
3. Open `index.html`.
4. Find the existing `<section id="projects" class="projects"> ... </section>`.
5. Replace that entire Projects section with the contents of `v4-0-projects-section.html`.
6. Commit:
   `V4.0 - Projects gallery`
7. Wait 30–60 seconds and refresh with Ctrl + F5.

Everything above the Projects section is intentionally unchanged.
